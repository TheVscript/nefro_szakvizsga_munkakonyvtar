# `_pdf/` — a letöltött PDF-ek, mesterpéldányban

Ide kerülnek a dokumentumok `forras_id` néven, két úton:

| Honnan | Ki teszi ide |
|---|---|
| Letöltött PDF | az `atnevezo.py` — felismeri és bemozgatja |
| **Böngészőből nyomtatott PDF** *(jogszabály, online cikk)* | **te, kézzel** — az `atnevezo.py` ezeket nem ismeri fel |

**Ez a hiteles forrás.** Az ellenőrzéskor (forrásjegyzék kipipálása)
ebben keresel vissza. **Ne töröld**, akkor sem, ha a `.md` már megvan.

Elnevezés: csak nagybetű, szám, kötőjel. Pl. `CKD-IRANYELV-BM-2025.pdf`
